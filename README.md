# GynaikoeidoPolis Γυναικοειδόπολις

## 현재 구현된 프로토타입 개요

작은 고정 정착지에서 제한된 노동력과 생산 시설을 관리하며 구조대가 도착할 때까지 생존하는 `5~10분` 분량의 3D 쿼터뷰 경영 프로토타입

- **핵심 흐름:** 자재 확보 → 건설 부지 활성화 → 노동력 배정 → 식량·자재 생산 → 생존 여부 판정
- **플레이 방식:** Scene에 미리 배치된 `6~8개` 건설 부지에 건물을 건설, 주민과 Gynaikoeideis의 노동력 및 자원 소비를 관리
- **목표:** 기한까지 일정 수 이상의 인간을 생존시키기
- **현재 범위:** 단일 소형 맵, 자재·식량, 생산 건물, 노동 배치, 시간·위기, 승패 및 재시작
- **보류한 기능:** 맵 절차적 생성, 청크 해금, 개별 주민 이동과 길찾기, 저장·불러오기 등 대규모 맵 기반 기능은 잠정 동결

세부 설정과 구현 단계는 [프로토타입 구현 계획](PrototypePlan.md)에서 확인 가능

## 배포판 게임 개요

- 장르: 생존 건설 경영 시뮬레이션
- 시점: 3D 쿼터뷰
- 개발 단계: 초기 프로토타입
- 사용 엔진: Unity 6 (`6000.5.7f1`)

### 핵심 게임 루프

자원 확보 → 건물 건설 → 주민 배치 → 생산 → 인구 유지 및 확장

### 튜토리얼에서 제공할 첫 번째 목표

모든 Thnetoi가 집을 가지고, Thnetoi와 Gynaikoeideis가 소비할 충분한 식량을 생산한다.

## 현재 개발 상태

| 영역 | 상태 | 설명 |
| --- | --- | --- |
| 시간 | 부분 구현 | 고정 틱, 일시정지, `1x`·`2x`·`3x`·`6x` 배속 |
| 카메라 | 부분 구현 | 이동, 회전, 높이 조절 |
| 맵·타일 | 설계 및 데이터 모델 작성 중 | 청크 크기와 기본 직렬화 데이터 정의 |
| 자원·건설·주민·직업·생산 | 계획 | 첫 마일스톤에서 구현 예정 |
| 저장·불러오기 | 계획 | 맵 및 시뮬레이션 상태 저장 예정 |

세부 작업 순서와 장기 계획은 [개발 로드맵](docs/Roadmap.md)에서 관리

## 실행

1. Unity에서 프로젝트를 연 후 Play Mode로 실행

### 현재 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 카메라 이동 |
| `Q` `E` | 카메라 회전 |
| 마우스 휠 | 카메라 높이 조절 |
| `Space` | 일시정지 전환 |
| `1` `2` `3` `4` | 각각 `1x` `2x` `3x` `6x` 배속 선택 |
